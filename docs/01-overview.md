# 情境設定與 KPI 指標定義

本篇說明三種比較情境的主動控制機制差異，以及模擬結束後人員結局與系統關鍵指標（KPI）的定義方式。

---

## 1. 三種比較情境與主動控制機制

同一棟建築配置、起火點與人員初始位置，會依序在以下三種模式中跑完完整的生命週期，並比較統計數據：

| 模式 | 技術說明與主動控制機制 |
| --- | --- |
| **DEFAULT** | **無智慧系統模式**：人物無法取得全域資訊，完全依賴個人局部視線（陰影投射 LOS）與嗅覺，透過視野內 BFS／朝出口方向推進進行逃生。 |
| **SMART** | **決策支援模式**：系統透過全域感測器網路進行 Dijkstra 路徑規劃並給予逃生指引。人物服從率為常數 **85%**（`COMPLIANCE_RATE = 0.85`），其餘時間退回個人直覺（DEFAULT 邏輯）行動；連線中斷或恐慌誤操作時同樣退回個人直覺。 |
| **HYBRID** | **決策支援＋備援主動控制模式**：除具備 SMART 模式的指引功能外，系統若偵測到某防火門周邊 5×5 範圍內存在危險（`fire == true` 或 `smoke > 0.5`），且該門目前未被任何人員的移動路徑（所在格、下一個決策點目標、快取路徑剩餘段、跨樓層目標）依賴中，會自動將其關閉，恢復阻絕能力；同時整體啟動局部排煙／抑制手段，將該情境下的通風換氣率（ACH）由密閉室內量級（0.5 ACH）提升至加壓排煙系統量級（12 ACH），使煙霧（`smoke`，能見度危害代理量）的稀釋速度大幅加快——這是 HYBRID 對「煙霧」濃度本身唯一的主動抑制途徑。此外會讓**煙味（`smell`，無害、僅用來觸發人員察覺的訊號量）**的生成與擴散量額外乘上 **0.85** 折減係數，兩者是分開追蹤、互不影響的物理量，折減對象請勿混淆（詳見 [03 · 火災與煙霧擴散模型](03-fire-model.md#煙味-0-85-折減係數的真正作用對象) 說明）。 |

三種模式在**同一場景（同一建築、同一起火點、同一人員初始位置與屬性）**下各自完整跑一次，藉此比較「原本在 DEFAULT 情境下能成功逃生的人，換成 SMART／HYBRID 情境後是否反而未能逃生」，作為系統「嚴重失誤機率」的量化依據（詳見 [05 · 決策支援與路徑規劃](05-routing.md)）。

## 2. 人員結局判定與關鍵指標（KPI）定義

每個人員在模擬結束後，必然歸類為以下三種最終狀態（`Outcome` Enum）之一：

* **ESCAPED（成功逃生）**：人員移動至任意標記為出口（`Exit`）的網格，且此時該人員仍處於存活狀態。
* **DEAD（不幸罹難）**：熱暴露劑量或一氧化碳吸入劑量，任一者累積達到致死劑量門檻（詳見 [02 · 累積劑量死亡判定](02-evacuation-model.md#累積劑量死亡判定)），死因另分為 `FIRE`（燒死）與 `CO_POISONING`（CO 中毒致死）兩類，供事後統計死因比例。
* **TRAPPED（受困）**：當建築內所有可停留格子皆已陷入危險（觸發 ASET，詳見 [03 · 溫度場與四判据 ASET](03-fire-model.md#溫度場與四判据-aset)）而模擬迴圈終止時，人員既未逃脫亦未死亡，仍滯留於建築內。

### 2.1 系統額外監測之 KPI 指標

* **高煙區暴露比例（High Smoke Exposure Rate）**：人員在移動路徑中，曾進入煙霧濃度大於 **0.7**（`HIGH_SMOKE_THRESHOLD`）網格的比例。
* **臨界 CO 暴露比例（Critical CO Exposure）**：人員累積之 CO 吸入劑量（`FED_CO`，詳見 [02 · CO 吸入劑量](02-evacuation-model.md#co-吸入劑量-fed_co)）達到或超過 **0.3**（`FED_INCAPACITATION`，ISO 13571 定義的失能門檻）的比例。
* **誤入危險路線比例（Wrong Route Rate）**：人員依當下已知資訊做出的移動決策，實際走到後卻發現目標格煙霧已超標（> 0.7）的比例，反映資訊落後於現場實況的程度。
* **改道成功率（Reroute Success Rate）**：曾發生「原定路線失效、被迫重新規劃」的人員中，最終仍成功逃生的比例。
* **弱勢對象辨識率（Vulnerable Identification Rate）**：`IMPAIRED`／`ELDERLY` 兩類人員中，系統（連線狀態下）成功辨識並標記為「需優先協助對象」的比例。
* **系統嚴重失誤機率（Mistake Rate）**：以「總人數加權平均」計算——同一批人在同一場景下，比較 DEFAULT 下原本能逃生、但換成 SMART／HYBRID 後反而未能逃生的人數比例。詳見下方 [2.2 節](#22-系統嚴重失誤機率-mistake-rate-的計算方式)。

### 2.2 系統嚴重失誤機率（Mistake Rate）的計算方式

模擬器針對每一組場景（同一建築、同一起火點、同一人員初始配置），依序執行 DEFAULT／SMART／HYBRID 三次完整模擬，逐一比對每位人員在三種情境下的結局：

* 若某人在 DEFAULT 下成功逃生（`ESCAPED`），但在 SMART 或 HYBRID 下反而未能逃生，即計入該模式的「系統嚴重失誤」人數。

「系統嚴重失誤機率」以**總人數加權平均**計算（人數越多的場景影響力越大），與其餘採「每場景等權重平均」計算的 KPI（逃生率／死亡率／受困率等）分母定義不同，報表中不建議直接跨欄位比較數值大小。
